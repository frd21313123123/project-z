# 🧟 Project Z: Global Outbreak Simulator

**Project Z** — это продвинутая интерактивная платформа для моделирования сценариев глобальных угроз (эпидемий, зомби-апокалипсисов или биологических катастроф). Используя возможности нейросетей последнего поколения (**Google Gemini**, **GPT-o3**, **Claude 3.5**), приложение создает детальную хронику событий, визуализирует их на карте мира и генерирует изображения с места событий в реальном времени.

## 🚀 Ключевые особенности

### 🧠 Двухуровневая ИИ-симуляция
В основе Project Z лежит архитектура **Master-Executor**:
1.  **Master Simulation (Стратег)**: Формирует глобальный план развития событий на выбранный период (день, неделя, месяц). Анализирует контекст, симптомы вируса и предыдущие события.
2.  **Executor (Исполнитель)**: Почасово расписывает события согласно плану Стратега, генерируя детальный лог и технические данные для карты.

### 🗺️ Интерактивная Стратегическая Карта
*   **Leaflet Integration**: Отображение динамических маркеров заражения, путей миграции и зон карантина.
*   **MAP_DATA Parsing**: Прямой парсинг JSON-данных из потока ответов ИИ для мгновенного обновления оперативной обстановки.
*   **Гео-привязка**: Возможность задать любую точку мира как эпицентр заражения.

### 🛰️ Визуальная Разведка (Drone Visuals)
*   Генерация изображений эпицентра в реальном времени с помощью **Imagen 3.0** или **DALL-E 3**.
*   Имитация интерфейса дрона-разведчика для глубокого погружения в атмосферу.

### ⚙️ Гибкая Настройка Сценария
*   **Matrix System**: Настройка "Матрицы поведения" и "Матрицы симптомов" по фазам.
*   **Multi-Provider**: Поддержка Google Gemini, OpenAI и OpenRouter (Claude, Llama и др.).
*   **Local Persistence**: Все настройки, API-ключи и сценарии сохраняются в браузере.

## 📦 Установка и запуск

### Требования
*   **Node.js** v20 или выше.
*   Ключ API для одной из поддерживаемых нейросетей (рекомендуется Google Gemini).

### Быстрый старт (Windows)
1.  Клонируйте репозиторий.
2.  Запустите `start-project.bat`. Скрипт сам установит зависимости и подготовит среду.
3.  В открывшемся интерфейсе перейдите в **Settings** и вставьте ваш API-ключ.

### Ручной запуск
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```
Приложение будет доступно по адресу `http://localhost:3000`.

## 📂 Структура проекта

*   `src/lib/gemini.ts` — ядро логики симуляции, управление промптами и стримингом.
*   `src/components/MapView.tsx` — логика отображения карты и гео-данных.
*   `src/lib/auth.ts` — управление профилями, сценариями и локальным хранилищем.
*   `src/App.tsx` — центральный контроллер симуляции и UI.

---

## 🛡️ Безопасность и Конфиденциальность
Project Z является **client-side** приложением. Ваши API-ключи хранятся только в `localStorage` вашего браузера и никогда не передаются на сторонние серверы, кроме официальных API провайдеров (Google/OpenAI).
